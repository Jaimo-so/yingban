## 推荐拍摄顺序

1. 在首页拍 `01-home.png`。
2. 进入“聊聊我看完的电影”，选择一部无隐私风险的示例电影，拍 `02-chat.png`。
3. 回首页进入“帮我找一部电影”，生成一组完整推荐卡后拍 `03-recommend.png`。
4. 进入“我的电影”，依次拍 `04-library.png`、`06-reflection.png` 和月度回顾 `07-recap-share.png`。
5. 从首页进入“阿映目前怎么理解我”，拍 `05-profile.png`。
6. 从首页进入“连续性与主动建议设置”，拍 `08-continuity-settings.png`。
